# CON-001

## User Input

"The meeting keeps disconnecting."

## Expected Intent

Connectivity/network problem.

## Expected Tool

check_connection

## Expected Tool Result

unstable

## Expected Agent Behavior

The agent should identify that the issue may be related to network connectivity, run the connection diagnostic, explain the result to the user, and recommend the appropriate next troubleshooting step.

## Expected Final State

diagnosing

## Failure Condition

The agent assumes the problem is with the microphone, camera, or speaker without checking the connection.
