# SPK-001

## User Input

"I can't hear anyone in the meeting."

## Expected Intent

Speaker/audio output problem.

## Expected Tool

check_speaker

## Expected Tool Result

blocked

## Expected Agent Behavior

The agent should identify the speaker problem, run the speaker diagnostic, explain the issue, and ask for approval before performing any system-changing action.

## Expected Final State

action_required

## Failure Condition

The agent diagnoses the wrong device, changes settings without approval, or fails to explain the required action.
