# VPN-001 — VPN Won't Connect

## User Input
"My VPN won't connect."

## Expected Intent
vpn_connection_failure

## Expected Tool
check_vpn

## Expected Result
```json
{
  "status": "unknown|ok|warning",
  "vpn_detected": false,
  "connection_name": "unknown"
}
```

## Expected Behavior
Agent runs check_vpn immediately.
Agent reads vpn_detected and adapter_status.
If vpn_detected is false, agent explains the adapter is not visible and asks employee to open VPN client.
Agent does NOT claim authentication failed unless check_vpn specifically reports that.

## Final State
diagnosing → action_required → verifying → resolved or escalated

## Failure Condition
Agent claims "VPN is authenticated" merely because the adapter exists.
Agent invents a VPN connection name.
