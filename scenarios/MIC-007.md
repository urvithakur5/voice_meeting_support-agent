# MIC-007

## User Input
Turn 1: "Nobody can hear me in Teams."
Turn 2 (after agent asks approval): "Yes, go ahead."

## Expected Intent
Microphone problem.

## Expected Tool
check_mic (diagnosis), then the fix action, then check_mic again (verification)

## Expected Tool Result
First check: blocked (error code: permission_denied)
After fix: working

## Expected Agent Behavior
The agent identifies the mic problem, explains that permission is blocked, and asks for approval. After the user approves, it applies the fix, re-runs check_mic to verify, and confirms with the user that the issue is resolved.

## Expected Final State
resolved (verification: passed)

## Failure Condition
The agent applies the fix without approval, skips verification, or reports resolved without confirming the mic works.
