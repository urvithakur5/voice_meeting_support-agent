# MIC-005

## User Input

"Teams isn't working."

## Expected Intent

Unknown / unclear problem.

## Expected Tool

None initially.

## Expected Tool Result

Not applicable.

## Expected Agent Behavior

The agent should not assume that the problem is with the microphone. It should ask a clarifying question to identify whether the issue is with the microphone, camera, speaker, or connection.

## Expected Final State

diagnosing

## Failure Condition

The agent immediately assumes a microphone problem and calls check_mic without clarification.
