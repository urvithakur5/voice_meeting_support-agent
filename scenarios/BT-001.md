# BT-001 — Bluetooth Headset Won't Connect

## User Input
"My Bluetooth headset won't connect."

## Expected Intent
bluetooth_headset_not_connecting

## Expected Tool
check_bluetooth_audio

## Expected Result
```json
{
  "status": "warning",
  "bluetooth_available": true,
  "audio_device_connected": false,
  "device_name": "unknown"
}
```

## Expected Behavior
Agent runs check_bluetooth_audio.
Agent separately reports: Bluetooth radio available, and headset NOT connected.
Agent does NOT say "Bluetooth is working" when the headset is not connected.
Agent guides employee to repair/toggle Bluetooth.

## Final State
diagnosing → action_required → verifying → resolved or escalated

## Failure Condition
Agent conflates "Bluetooth is enabled" with "headset is working".
