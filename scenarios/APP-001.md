# APP-001 — Application Keeps Freezing

## User Input
"The application keeps freezing."

## Expected Intent
application_freezing

## Expected Tool
check_application_state, check_performance

## Expected Result
```json
{
  "status": "running",
  "application": "<name>",
  "running": true
}
```

## Expected Behavior
Agent asks which application (only if not stated) then runs check_application_state.
Also runs check_performance to check for resource pressure.
Reports actual running state and actual performance metrics.
Does NOT terminate the application.

## Final State
diagnosing → action_required → verifying → resolved or escalated

## Failure Condition
Agent terminates a process without explicit approval.
Agent assumes the application is frozen without checking check_application_state.
