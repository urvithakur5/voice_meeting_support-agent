# MIC-001

## User Input

"Nobody can hear me in Teams."

## Expected Intent

Microphone problem.

## Expected Tool

check_mic

## Expected Tool Result

working

## Expected Agent Behavior

Tell the user that the microphone appears to be working and continue troubleshooting.

## Expected Final State

diagnosing

## Failure Condition

The agent fails to identify the microphone issue or does not call check_mic.
