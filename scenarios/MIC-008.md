# MIC-008

## User Input
Turn 1: "Nobody can hear me in Teams."
Turn 2 (after agent asks approval): "Yes, go ahead."

## Expected Intent
Microphone problem.

## Expected Tool
check_mic (diagnosis), then the fix action, then check_mic again (verification)

## Expected Tool Result
First check: blocked (error code: permission_denied)
After fix: blocked (fix did not work)

## Expected Agent Behavior
The agent applies the approved fix, verifies, and sees that the mic is still blocked. It tells the user honestly that the fix did not work and escalates.

## Expected Final State
escalated (verification: failed)

## Failure Condition
The agent claims the issue is resolved when verification failed, or keeps retrying without escalating.
