# MIC-003

## User Input
"My mic isn't working."

## Expected Intent
Microphone problem.

## Expected Tool
check_mic

## Expected Tool Result
error (error code: timeout)

## Expected Agent Behavior
The agent should handle the tool timeout gracefully. It should not crash or give a false diagnosis. It should retry the tool once. If it times out again, explain that the diagnostic check could not be completed and escalate.

## Expected Final State
escalated

## Failure Condition
The agent crashes, gives an incorrect diagnosis, or continues as if the diagnostic tool worked successfully.
