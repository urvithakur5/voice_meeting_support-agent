# MIC-003

## User Input

"My mic isn't working."

## Expected Intent

Microphone problem.

## Expected Tool

check_mic

## Expected Tool Result

timeout

## Expected Agent Behavior

The agent should handle the tool timeout gracefully. It should not crash or give a false diagnosis. It should explain that the diagnostic check could not be completed and provide a fallback or escalation option.

## Expected Final State

escalated

## Failure Condition

The agent crashes, gives an incorrect diagnosis, or continues as if the diagnostic tool worked successfully.
