# MIC-006

## User Input

"My mic isn't working. I already told you that."

## Expected Intent

Microphone problem.

## Expected Tool

check_mic

## Expected Tool Result

working

## Expected Agent Behavior

The agent should recognize that the user has already provided the microphone issue and should not repeatedly ask for the same information. It should use the existing context and continue troubleshooting.

## Expected Final State

diagnosing

## Failure Condition

The agent asks the user to repeat information that has already been provided or starts the diagnosis from the beginning without using the existing context.
