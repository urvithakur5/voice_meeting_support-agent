# MIC-006

## User Input

"My mic isn't working. I already told you that."

## Expected Intent

Microphone problem.

## Expected Tool

check_mic

## Expected Tool Result

working

## Expected Agent Behavior
Tell the user that the microphone appears to be working. Ask one clarifying question (for example, whether others can see them or whether they can hear others) and run check_speaker or check_connection based on the answer.

## Expected Final State

diagnosing

## Failure Condition

The agent asks the user to repeat information that has already been provided or starts the diagnosis from the beginning without using the existing context.
