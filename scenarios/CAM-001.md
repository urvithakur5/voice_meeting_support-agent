# CAM-001

## User Input

"My camera isn't working in the meeting."

## Expected Intent

Camera problem.

## Expected Tool

check_camera

## Expected Tool Result

blocked

## Expected Agent Behavior

The agent should identify the camera issue, run the camera diagnostic, explain that the camera is blocked or unavailable, and ask for approval before performing any system-changing action.

## Expected Final State

action_required

## Failure Condition

The agent diagnoses the problem incorrectly, changes settings without approval, or fails to communicate the required action to the user.
