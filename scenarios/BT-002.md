# BT-002 — Headphones Connected But No Sound

## User Input
"My headphones are connected but I have no sound."

## Expected Intent
bluetooth_audio_no_output

## Expected Tool
check_bluetooth_audio, check_speaker

## Expected Result
```json
{
  "status": "warning",
  "bluetooth_available": true,
  "audio_device_connected": true,
  "audio_endpoint_active": false,
  "device_name": "<observed>"
}
```

## Expected Behavior
Agent runs check_bluetooth_audio.
Observes audio_device_connected true but audio_endpoint_active false or speaker output not routed to headset.
Agent explains the device is paired but not set as the active audio endpoint.
Agent guides employee to set as default device in Sound Settings.

## Final State
diagnosing → action_required → verifying → resolved or escalated

## Failure Condition
Agent claims headphones are working because bluetooth_available is true.
